# voice-narration

## Kapan dipakai
Saat user meminta: menyiapkan naskah narasi bahasa indonesia.

## Prosedur
1. Identifikasi kebutuhan user dan output akhir.
2. Tulis naskah natural, pecah per kalimat, tandai jeda dan pengucapan; tentukan gaya suara.
3. Lakukan pemeriksaan hasil dan laporkan file keluaran serta keterbatasan.
