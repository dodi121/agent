# Hermes NEXUS 40 — Ubuntu

40 named agent profiles + 20 original Hermes skills, focused on content, narration, coding and operations. These are NOT verified transcriptions of skills from the linked YouTube video; that video's transcript was inaccessible during creation.

## Install
```

bash install.sh
hermes skills list
hermes
```
Run `bash scripts/doctor.sh` to check installation. Install only as the same Linux user that runs Hermes; no sudo. The installer copies SKILL.md to ~/.hermes/skills and stores this project in ~/hermes-nexus-40; it does not edit credentials, provider settings or gateway config. Existing skills with the same names are skipped, not overwritten.

## Use
In terminal or Telegram ask: `Baca ~/hermes-nexus-40/AGENTS.md dan kerjakan ide konten coding dengan NEXUS.`
Or `/coding-idea-lab buat ide aplikasi Telegram` / `/voice-narration buat skrip 60 detik`.

## Optional cron
Review scripts/cron-examples.sh; run `bash scripts/cron-examples.sh` only after confirming your provider, available tools, costs and Hermes gateway running. This creates 3 scheduled jobs.

## Voice and video
TTS and video require separately installed and configured providers/tools. ffmpeg can be installed via Ubuntu package manager if desired; no audio/video is generated by the installer itself.

## Operational notes
- Use `hermes gateway setup` for Telegram, and start gateway according to the installed Hermes version.
- `hermes cron list`, `hermes cron status` to inspect jobs.
- No auto-publish, automatic server changes or credential exposure.
